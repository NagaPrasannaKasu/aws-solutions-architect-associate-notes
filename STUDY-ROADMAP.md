# Study roadmap (adapt to your exam date)

| Phase | Objective | Evidence |
| --- | --- | --- |
| 1. Foundation | AWS global infrastructure, IAM, VPC fundamentals, shared responsibility | Explain baseline concepts without notes |
| 2. Core services | Compute, storage, databases, networking, integration | Write service comparisons and design decisions |
| 3. Architecture | Security, resilience, performance, cost | Draw original diagrams and analyze trade-offs |
| 4. Hands-on | Small labs with budget and cleanup plans | Record **actual** findings and screenshots without secrets |
| 5. Revision | Domain checklist, practice questions from authorized sources | Log weak areas and revisit AWS documentation |

## Weekly loop
1. Capture raw ideas in Google Docs.
2. Convert 2–3 stable topics to Markdown, with official references.
3. Complete one scenario comparing at least two valid architectures.
4. Check exam-domain progress, review gaps, and revise older notes.
5. Optionally repurpose one polished lesson to Medium/LinkedIn.

**Rule:** Study time > publishing time. Focus on architectural reasoning, not memorizing every console click.
