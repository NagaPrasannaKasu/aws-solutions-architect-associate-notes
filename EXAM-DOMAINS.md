# SAA-C03 exam-domain checklist

**Official blueprint:** [AWS exam guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03.html). Checked 2026-11-18. Checkboxes below are **study actions**, not a claim of complete exam coverage. Consult the guide for the authoritative task definitions.

## Domain 1 — Design Secure Architectures (30%)
- [ ] Secure access to AWS resources: IAM roles, policies, federation, least privilege.
- [ ] Secure workloads and applications: VPC security groups, NACLs, WAF, Shield, endpoints.
- [ ] Determine data security controls: KMS, S3 encryption, ACM, Secrets Manager, backups.
- [ ] Explain shared responsibility and account governance.

## Domain 2 — Design Resilient Architectures (26%)
- [ ] Design scalable and loosely coupled architectures: ELB, Auto Scaling, queues, events.
- [ ] Design highly available and fault-tolerant architectures: AZs, health checks, failover.
- [ ] Compare RTO/RPO, backup/restore, pilot light, warm standby, active/active.
- [ ] Choose database availability and replication strategies.

## Domain 3 — Design High-Performing Architectures (24%)
- [ ] Select performant/scalable storage: S3, EBS, EFS, FSx.
- [ ] Select performant/elastic compute: EC2 families, ASG, Lambda, containers.
- [ ] Select database services: RDS/Aurora, DynamoDB, cache, read replicas.
- [ ] Select performant networks: VPC, Route 53, CloudFront, Global Accelerator.
- [ ] Assess ingestion and transformation: SQS, Kinesis, Glue, transfer patterns.

## Domain 4 — Design Cost-Optimized Architectures (20%)
- [ ] Choose lower-cost storage and lifecycle policies for access patterns.
- [ ] Compare compute purchasing and scaling models for workload patterns.
- [ ] Compare database pricing and capacity models.
- [ ] Assess network and data transfer costs.
- [ ] Use budgets, Cost Explorer, tagging, and Well-Architected cost principles.

## Self-assessment

For each checkbox: (1) explain it unaided; (2) justify a choice against alternatives; (3) identify security, availability and pricing caveats; (4) solve an original scenario.
